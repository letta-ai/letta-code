Execute JavaScript in an isolated QuickJS sandbox to work with agent-scoped MCP tools only. Built-in tools (Read, Bash, Write, Workflow) and other non-MCP tools are not callable here; call those directly instead. No filesystem, network, Node APIs, imports, or process globals are available. Use `await tool.list()` for up to 100 MCP names and descriptions, `await tool.search(query)` to discover further names, `await tool.describe(name)` for an input schema, and `await tool.call(name, args)` to invoke an MCP tool. The script is an async function body: top-level `await`, `return`, `text(value)`, and `console.log(value)` are supported. Each MCP call checks permissions and may require approval; unavailable tools fail closed. Maximum 32 calls and a two-minute deadline. Return concise results rather than printing large tool responses.
