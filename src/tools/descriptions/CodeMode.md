Execute JavaScript in an isolated QuickJS sandbox that can call your other tools, including built-in tools (Read, Bash, Grep, ...) and agent-scoped MCP tools. Use it to run independent calls in parallel, chain calls without extra turns, or filter large tool output so only the result you need comes back. The script itself has no filesystem, network, Node APIs, imports, or process globals; it acts only through tools. Call a tool as `await tools.<name>(args)` with one object argument, for example `await tools.Read({ file_path: "/abs/path" })` or `await tools.mcp__server__tool({ ... })`; names with characters that are invalid in identifiers use `_` (or `tools["name"]`). `ALL_TOOLS` lists `{ name, description }` for every callable tool, and `await describeTool(name)` returns a tool's input schema. Built-in tools resolve to their text output; MCP tools resolve to structured content, else parsed JSON text, else the raw content array. A failed call throws. The script is an async function body: top-level `await`, `return`, `text(value)`, and `console.log(value)` are supported. Each call checks permissions and may require approval; unavailable tools fail closed. Maximum 32 calls and a two-minute deadline. Return concise results rather than printing large tool responses.
